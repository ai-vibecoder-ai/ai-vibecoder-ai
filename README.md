## 🛠️ Моя лаборатория

### AI-пилотируемая разработка
- `Claude Code` — основной cockpit
- `Claude API` / `Anthropic` — мультиагентные пайплайны
- `OpenAI API` — генерация, аналитика, классификация
- Другие LLM — под задачу, не под хайп

### Автоматизация и веб
- `Python` — обработка данных, скрипты, бэкенд
- `JavaScript / Node.js` — интеграции, парсеры, боты
- `Bash` — конвейеры, cron, CLI-магия
- `REST API / JSON` — связь между системами

### Медиа-конвейер
- `Pillow / ImageMagick` — обрезка, водяные знаки, ресайз
- `Sharp / Python-скрипты` — веб-оптимизация
- Пакетная обработка сотен файлов за один запуск

### SEO и контент
- Технический SEO, Core Web Vitals, структура
- `WordPress / Headless CMS / кастомные движки`
- `Markdown / JSON` как формат данных

## ⚡ Принципы работы

1. **Автоматизировать первым делом** — повторяющаяся задача = кандидат на конвейер.
2. **AI как соисполнитель** — он генерирует, я редактирую, проверяю и масштабирую.
3. **Данные важнее догадок** — в SEO и аналитике решения основаны на фактах.
4. **Простота масштабируется** — сложные системы начинаются с простых скриптов.
