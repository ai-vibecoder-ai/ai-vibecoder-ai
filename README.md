# Vibecoder · AI-разработчик · SEO · BA · SA

Создаю автоматизированные контентные системы и цифровые инструменты на стыке AI, аналитики и веб-разработки. Превращаю рутинные процессы в масштабируемые решения: от генерации контента до обработки медиа и SEO-оптимизации.

## Направления работы

- **Vibecoding** — разработка и автоматизация с помощью AI-ассистентов
- **SEO** — техническая оптимизация, структура сайтов, контентная стратегия
- **Business Analysis** — анализ бизнес-процессов, требований и метрик
- **System Analysis** — проектирование архитектуры, интеграций и данных

## Проекты

### Контентный завод для футбольного клуба
Автоматизированная система генерации и публикации контента для футбольного клуба: новости, матч-центры, статистика, материалы для социальных сетей. Позволяет команде оперативно выпускать контент в едином стиле и формате.

**Ключевые решения:** генерация текстов, структурирование данных, интеграция с сайтом и каналами распространения.

---

### Автоматизатор обработки фото
Инструмент для пакетной обработки изображений: обрезка, нанесение водяных знаков, оптимизация размера и формата под требования сайта. Сокращает время подготовки медиа-контента в десятки раз.

**Стек:** Python, Pillow, CLI-автоматизация.

---

### Контентный завод для сайта психолога
Система создания и публикации экспертного контента для сайта психолога: статьи, консультации, FAQ, кейсы. Автоматизирует рутину копирайтинга и помогает поддерживать регулярное наполнение ресурса.

**Ключевые решения:** генерация SEO-текстов, структура разделов, адаптация под целевую аудиторию.

---

### Контентный завод для сайта агентства недвижимости
Платформа автоматической генерации объектов, описаний квартир, районов и SEO-страниц для агентства недвижимости. Обеспечивает масштабируемое наполнение каталога без ручного труда.

**Ключевые решения:** шаблонизация, генерация уникальных описаний, интеграция с каталогом объектов.
